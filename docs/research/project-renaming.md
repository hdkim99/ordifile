# Project renaming research

- Search date: 2026-08-16
- Access date: 2026-08-16
- Final selected name: **Ordifile**

- Status: approved for repository, distribution package, import package, and CLI rename
- Scope: GitHub repositories and accounts, PyPI, npm, conda-forge, crates.io,
  general web results, academic and research-data indexes, scientific and commercial
  software, and accessible official trademark search systems.

## Reason for rename

The current name, LabConvert, collides with an existing GitHub repository and is also
used by active services, including a medical-laboratory document conversion service.
The project needs a more searchable identity before a first package release. This
research is a technical collision screen, not a legal trademark clearance.

## Search method and limitations

An initial set of 31 pronounceable, ASCII-compatible candidates was screened. Exact
normalized names were checked in package registries, and exact names were checked in
GitHub repository and account search. The strongest names were then checked in general
web search, commercial and scientific software contexts, Crossref, OpenAlex, DataCite,
Zenodo, PubMed, USPTO Trademark Search, and EUIPO eSearch plus.

An absent registry record or exact trademark result only means that the queried record
was not found on the search date. It does not reserve the name, establish ownership, or
show that similar marks, unregistered rights, company names, domains, or national rights
do not exist. WIPO automated querying was not performed because its terms restrict it;
KIPRIS and other national databases remain unresolved.

Python distribution names are compared after lowercase normalization and replacement
of runs of `.`, `_`, and `-` with `-`, as specified by the
[Python Packaging Authority](https://packaging.python.org/en/latest/specifications/name-normalization/).
The shortlisted names contain no separators, so their normalized forms are unchanged.

## Trademark concerns

The [USPTO Trademark Search](https://tmsearch.uspto.gov/search/search-results) exact
combined-mark queries and [EUIPO eSearch plus](https://euipo.europa.eu/eSearch/) exact
queries returned zero results for each shortlisted candidate. USPTO guidance on
[federal trademark searching](https://www.uspto.gov/trademarks/search/federal-trademark-searching)
requires searches for similar spelling, pronunciation, meaning, and commercial
impression, not only exact text.

The [WIPO Global Brand Database](https://www.wipo.int/en/web/global-brand-database/index)
was not automatically queried because its
[terms of use](https://www.wipo.int/en/web/global-brand-database/terms_and_conditions)
restrict automated querying. WIPO's
[availability guidance](https://www.wipo.int/en/web/madrid-system/check-availability)
also recommends national and regional searches. WIPO, KIPRIS, other national systems,
company names, domains, app stores, common-law use, and confusingly similar marks are
therefore unresolved.

## Decision and recommendation

The repository owner selected **Ordifile** after reviewing the evidence and tradeoffs.
The approved identity is:

- Display name: `Ordifile`
- Repository: `ordifile`
- Python distribution and import package: `ordifile`
- CLI: `ordifile`

Ordifile was selected because it had strong search uniqueness in the checked sources,
is not tied to one analytical technique, connects semantically to ordered files, and is
short enough for a practical CLI. No exact-name GitHub repository/account or package
record was found in the checked registries on the search date.

The evidence ranking before the owner decision was:

1. **Ordifile** — best balance of search uniqueness, CLI suitability, and instrument
   universality; weaker as a distinctive mark and pronunciation is not fully obvious.
2. **Specmeld** — shortest and most brand-like; may be interpreted as spectroscopy or
   software specifications rather than all instrument data.
3. **Vialloom** — memorable laboratory and data-weaving imagery; less suitable for
   instruments that do not use vials.
4. **Assayloom** — clear scientific character; may imply life-science assays.
5. **Sortavia** — memorable and broad, but an existing Finnish word form creates an
   avoidable cross-language concern.

The approval is a project naming decision, not a representation that the name is
legally clear. Exact GitHub repository/account and PyPI normalized-name checks must be
repeated immediately before the remote rename. Before commercial distribution or a
trademark filing, obtain jurisdiction-specific professional clearance.
