# Ordifile v0.2.0 release candidate — not published

The protected annotated `v0.2.0` tag is retained as an immutable audit record, but no
v0.2.0 package was published to TestPyPI or PyPI and no GitHub Release was created.

The tag workflow stopped in the normal test suite before artifact build or upload. A
synthetic release-verifier test for version 0.1.0 inherited the real workflow tag
version instead of receiving its explicit synthetic tag. The product code and package
candidate were not implicated.

The regression test was isolated without weakening the release verifier's real
tag/version gate. The same reviewed Experimental reader feature set is prepared for
publication as v0.2.1. The `v0.2.0` tag is not moved, deleted, or reused.
