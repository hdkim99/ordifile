# Examples

`basic/` contains three small, fully synthetic GC peak-table exports. Their names demonstrate
natural filename sorting (`sample_1`, `sample_2`, `sample_10`).

`unicode/` contains one small, fully synthetic peak-table export whose filename uses a
non-ASCII (Korean) name, demonstrating that normal Unicode input filenames are preserved
through to the `Samples` sheet.

`pilot/` contains two neutral, public-safe synthetic tables plus a single mapping, a
Mapping Set, and an embedded-Mapping-Set Conversion Recipe. It demonstrates explicit
mapping and repeated laboratory configuration without any vendor-generated bytes. The
JSON files are local configuration examples: real laboratory recipes can contain private
headers or labels and should not be posted publicly without review.

From the repository root after installation:

```console
ordifile convert examples/basic --sort filename --output Ordifile_Result.xlsx
ordifile convert examples/unicode --extension .csv --sort filename --output Ordifile_Result.xlsx
ordifile convert examples/pilot/inputs --recipe examples/pilot/laboratory.recipe.json \
  --output Pilot_Result.xlsx --dry-run
ordifile convert examples/pilot/inputs --recipe examples/pilot/laboratory.recipe.json \
  --output Pilot_Result.xlsx
```

The command creates one workbook and does not modify the example inputs.
See the [researcher pilot checklist](../docs/user/pilot-checklist.md) for the expected
routes, values, units, and workbook review order.
