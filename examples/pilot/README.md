# Public-safe researcher pilot

This directory contains neutral synthetic tables and strict local configuration examples.
It contains no vendor-generated bytes and does not demonstrate exact vendor support.

- `inputs/template-a.csv`: RT, Area, Height, and explicit Compound columns.
- `inputs/template-b.tsv`: Run, RT, and Area columns with different units.
- `template-a.mapping.json`: one explicit mapping.
- `templates.mapping-set.json`: two exact-structure Mapping Profiles.
- `laboratory.recipe.json`: the same Mapping Set embedded in a portable Recipe.

Run the commands and workbook checks in
[`docs/user/pilot-checklist.md`](../../docs/user/pilot-checklist.md). The synthetic values
exist only to make source-to-workbook comparison unambiguous. Real Mapping and Recipe JSON
can contain private headers or labels and should remain local.
